LUNE OBJECT 카페24 스킨 시안

- index.html: 메인
- products.html: 상품목록
- product-detail.html: 상품상세
- cart.html: 장바구니
- login.html / signup.html: 로그인 / 회원가입
- notice.html / reviews.html / qna.html: 게시판
- board-view.html / board-write.html: 게시글 보기 / 작성

모든 페이지는 페이지별 인라인 CSS, 공통 헤더·푸터, 순수 HTML/CSS/바닐라 JS로 구성했습니다.
구매·결제·회원 기능은 디자인 시안이며 카페24 모듈 연결이 필요합니다.
강조색은 각 문서의 :root { --point:#A98C70; } 한 곳에서 수정할 수 있습니다.
